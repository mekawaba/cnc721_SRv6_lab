# Crosswork Network Controller Demo Guide

Demo guide for Cisco Crosswork Network Controller (CNC) 7.2.1 with an SRv6 (uSID) network.

## Published Page
Access https://mekawaba.github.io/cnc721_SRv6_lab

## Local preview

```text
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
mkdocs serve
```

Open http://127.0.0.1:8000 in a browser.
